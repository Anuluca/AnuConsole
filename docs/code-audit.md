## 算法与运行时

| 问题 | 修改 | 可验证结果 |
| --- | --- | --- |
| 每个 GitHub 仓库都线性扫描关联站点 | 一次建立忽略大小写的 Map 索引，重复关联保留首项 | 匹配复杂度由 O(n×m) 降为 O(n+m)；增加大小写、重复关联和权限过滤测试 |
| 每条站点记录重新解析允许列表 | 每次业务操作构造一次 Set，不跨请求缓存权限配置 | 批量扫描不再重复拆分字符串，查找使用 Set |
| 趋势交互重复计算坐标和格式化文本 | 抽出纯函数 `buildTrend`，按报表与指标记忆计算结果 | 悬停只切换选中点；空值、单点、15 万行计算测试通过 |
| 对整组数值展开调用 `Math.max` | 改为 `reduce` | 大数组不再受函数参数数量上限约束；不代表浏览器适合渲染 15 万个图形节点 |
| 父组件状态变化重绘无关报表 | 报表表格与趋势图使用 `memo`，报表索引和表格列使用 `useMemo` | 数据引用不变时避免重复生成对应内容 |
| 登录动画每次输入重新高亮所有行 | 按行拆分、记忆组件 | 已完成行不再每 36ms 重复分词和生成高亮节点 |
| 所有导航链接订阅整个进度状态 | 分离进度值与稳定的上报函数上下文 | 进度变化不再让所有上报组件消费新的上下文对象 |
| 重复点击当前菜单触发同页导航 | 普通点击当前菜单只关闭手机菜单，保留修饰键/新标签行为 | 不重复请求当前路由；不是对未解决导航超时的修复结论 |
| 后台标签持续轮询构建状态 | 隐藏时停用定时器，恢复可见立即刷新，卸载清理 | 不积累隐藏页面的周期请求 |
| 列表搜索重复标准化查询词 | 循环外统一转换大小写和裁剪 | 搜索语义保持不变，减少逐项重复运算 |

### 请求与资源

- 功能调整的两个连接标识改用 `/api/infrastructure/connections`：一个浏览器读取接口，服务端并行请求两个平台，分页大小均为 1，只返回连接布尔值。
- 连接状态接口仍先执行 `requireUser()`；单个平台失败不影响另一端结果。异常平台信息、凭据和业务记录不返回浏览器。
- React 开发严格模式可能取消并重启同一个读取请求；未关闭严格模式，也未增加跨用户的全局数据缓存。
- Anton 预加载从根布局移至登录页，后台不再为未使用的登录字体发起下载。UnboundedSans 与 Adobe 字体配置保持原样。
- 未发现逐条业务记录发起上游请求的 N+1 模式；站点写入前的归属读取属于安全校验，不为减少请求而删除。
- GitHub 关联项目扫描仍保留既有分页上限，未引入可能混用凭据或隐藏权限变更的跨请求缓存。

- 单元测试：37 项通过，包含连接状态授权、部分平台失败、Map 匹配语义与大数组计算。
- `npm run typecheck`、`npm run build`、`git diff --check`：通过。
- 新增桌面/手机布局回归：排列比例、等高、指标对齐、连接标识和溢出检查。
- 现有页面回归覆盖开关保存、DNS、Netlify、主题、导航、字体、滚动与减少动态效果。
- 全量页面回归结果：82 项中 75 项通过、4 项失败、3 项跳过。失败涉及桌面/手机连续导航、桌面跨项目运维跳转、手机轮询后切换路由；这些导航异常在改动前基线中也已出现。
- 对连续导航和轮询相关 6 项单独复测：3 项通过、3 项失败，失败仍为桌面/手机控制台连续导航、手机运维跳转。不能宣称全量回归通过，也不能仅以开发编译解释所有失败；导航根因仍需进一步定位。
- 最后单独验证：新增部署轮询测试桌面/手机均通过；控制台连续导航桌面/手机仍失败。普通点击当前菜单的优化未消除该问题，不将其表述为修复。
- 未提供 `E2E_ADMIN_PASSWORD` 时，真实登录转场用例明确跳过，不将其计为通过；角色权限由模拟会话单元测试覆盖。
- 回归发现旧测试以唯一 `.site-link` 定位手机端元素，已改为定位可见链接；主题边界测试冻结首屏时钟，避免加载时间越过 07:00。
