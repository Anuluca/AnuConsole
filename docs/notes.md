# Notes 编辑与预览

- 新建、编辑使用 ManagementModal，不保存或恢复本地草稿，关闭弹窗或刷新丢弃未保存内容。发布／保存按钮位于固定页脚。不自动打开编辑器、不转移焦点。
- 写入继续通过 requireAdmin、同源校验及 If-Match 版本校验；并发冲突保留编辑。测试写入全部模拟，不操作线上 R2。
- `src/lib/note-renderer/` 是 Anutrium `scripts/sync-note-preview.mjs` 的生成结果：渲染器、正文 CSS 和字体来自同一个网站源。编辑器和查看弹窗均使用 NotePreview，不再另建 MarkdownIt 配置。
- 修改网站渲染或样式后，在 Anutrium 运行 `node scripts/sync-note-preview.mjs`；`--check` 校验两端一致。后台构建使用本仓库内文件，不依赖相邻仓库。
- Notes 预览独立使用官方普惠体 2.0 原始 700／900 字体（`public/fonts/notes/`），不引入 Typekit；后台其余界面仍使用原系统字体。
- 新增／编辑／查看弹窗桌面为最大可用 16:9、手机为 3:4，根据视口宽高限制尺寸；长代码不能撑大外框。外框 padding 与底部偏移沿用网站动态根字号公式，正文四周留白相同。
- 图片支持点击／Enter／空格查看原图，Escape 仅关闭最上层弹窗；脚注跳转只滚动弹窗内部。嵌套 dialog 的 cancel 事件停止向父弹窗传播。
- `tests/notes-preview.spec.ts` 比较两站同一篇笔记的 HTML、16:9 比例、行距、字重、字体、行号固定、四边 padding 及图片开关，并覆盖直达、刷新、路由进入后刷新；手机包含 WebKit。

## 笔记隐藏

- AnuConsole 列表提供「隐藏」开关，点击即按当前 ETag 条件保存；新建／编辑表单也可设置，随发布／保存提交。默认关闭，旧文件缺少字段时保持显示。
- Markdown 元信息新增可选 `hidden: true/false`，隐藏状态随正文一次写入 R2，并同步列表索引。隐藏后公开列表排除该笔记，公开详情返回 404；后台仍可查看、编辑、删除或关闭隐藏开关恢复显示。
- 版本冲突时不更新开关，保留服务器内容并提示刷新；仅管理员可写入，沿用同源校验和原始 `X-Note-Version`。
- Anutrium 刷新后读取最新状态；已打开页面仍遵循原有 60 秒列表缓存。需先部署支持此字段的 Worker，再发布 AnuConsole。

- 查看弹窗与网站共用最新擦入：标题 1.8 秒，标签先快速闪烁两下，再播放日期的两次闪烁（各 0.28 秒），保留无缝衔接与显示完成后的 0.4 秒居中停顿。

- 编辑器「插入内容块」提供图片列表、工具卡和分组标签页表单，在正文选区生成 Markdown，不改变发布与 ETag 并发校验流程。
